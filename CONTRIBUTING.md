# Contributing

Issues and pull requests are welcome, especially game integrations, wallet integrations, reward systems, documentation improvements, security review and frontend examples.

Use Node.js 22 and run `npm ci`, `npm run compile` and `npm test` from the root. For frontend changes also run `npm ci`, `npm test`, `npm run lint` and `npm run build` inside `frontend/`.

Describe the problem, final behavior and validation in your pull request. Keep contract economics and metadata unchanged unless the maintainer explicitly agrees to a separate design change. QFC is project branding; the supplied contract's symbol is QFT. Examples must read or accurately reflect actual metadata.

Never submit real keys, private environment files or invented deployment addresses. Do not claim prices, returns, listings, audits or partnerships without evidence. Report security concerns as described in [Security](docs/SECURITY.md). Contributions are covered by the existing MIT license.
